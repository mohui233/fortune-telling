### YL-0001
- 典籍： 渊海子平·继善篇
- 原文： 欲知贵贱，先观月令乃提纲，次断吉凶，专用日干为本主。
- 白话： 判断命局层次先看月令（出生月份的地支五行环境），再以日干为核心断吉凶。
- 适用前提： 已有完整四柱；月令未被严重破坏。
- 层级： 核心论断
- 流派： 子平格局
- 反例边界： 月令被两次以上冲刑或合化他行时，提纲之力受损，须结合全局斟酌，不可单凭月令下断。

### YL-0002
- 典籍： 子平真诠·论用神
- 原文： 八字用神，专求月令。以日干配月令地支，而生克不同，格局分焉。
- 白话： 格局法的取用先从月令找：日干与月令地支的生克关系，决定格局类型。
- 适用前提： 已知日干与月支藏干透干情况。
- 层级： 核心论断
- 流派： 子平格局
- 竞合： WS-0001（旺衰法主张先辨衰旺真机）——两法并用：先按月令定格，再以旺衰定喜忌。
- 反例边界： 月令藏干皆不透且本气受制、或成从格化格时，专求月令之法不适用，须另寻用神。

### GJ-0001
- 典籍： 子平真诠·论用神
- 原文： 财官印食，此用神之善而顺用之者也；煞伤劫刃，此用神之不善而逆用之者也。
- 白话： 财官印食四吉神宜"顺用"（生扶保护）；杀伤劫刃四凶神宜"逆用"（克制化泄）。
- 适用前提： 格局已定；成格之神明确。
- 层级： 操作规则
- 流派： 子平格局
- 反例边界： 吉神过多为病时亦可逆用（如印多埋身须财损印）；凶神为用神时反宜顺其势（如身强用杀）。

### WS-0001
- 典籍： 滴天髓（任铁樵注本）
- 原文： 能知衰旺之真机，其于三命之奥，思过半矣。
- 白话： 能真正判断日主与全局五行的强弱态势，命理的难点就解决一大半了。
- 适用前提： 四柱齐全，藏干与生克关系已明。
- 层级： 核心论断
- 流派： 旺衰法
- 竞合： YL-0002（格局法主张用神专求月令）——先定格后辨衰旺，两者矛盾时以调候与全局流通仲裁。
- 反例边界： 从格从化格局中"衰旺"以势论不以常规生克论，常规判法不适用。

### WS-0002
- 典籍： 滴天髓（任铁樵注本）
- 原文： 既识中和之正理，而于五行之妙，有全能焉。
- 白话： 懂得"中和平衡"的正理，五行变化的妙处就能全面把握。
- 适用前提： 中和偏枯程度已评估。
- 层级： 核心论断
- 流派： 旺衰法
- 反例边界： 从格反以偏为美（顺势），不可强求中和；调候需求急迫时（夏水冬火），中和让位于调候。

### TH-0001
- 典籍： 穷通宝鉴·论木
- 原文： 春月之木，余寒犹存。喜火温暖，则无盘屈之拘。
- 白话： 春天（寅卯月）出生的木命还有寒气，喜火来暖局，生机才能舒展。
- 适用前提： 日主为木，生于寅卯月（可推广至冬末春初余寒未尽的命局）。
- 层级： 操作规则
- 流派： 调候法
- 反例边界： 木已极旺成林时，火多反泄气太过，调候让位于旺衰；水旺木漂之局先取土制水，不急取火。

### TH-0002
- 典籍： 穷通宝鉴·论木
- 原文： 夏月之木，根干叶燥……欲得水盛而成滋润之力，诚不可少。
- 白话： 夏天（巳午月）出生的木命燥热，急需充足的水来滋润。
- 适用前提： 日主为木，生于巳午未月（可推广至一切夏生偏燥命局）。
- 层级： 操作规则
- 流派： 调候法
- 反例边界： 身弱又无根之夏木，大水反致漂木，须先有根或有土挡水；从旺炎上之格不取水逆势。

### TH-0003
- 典籍： 穷通宝鉴·论金
- 原文： 夏月之金，尤为柔弱，形质未备，更忌身衰。
- 白话： 夏天（巳午未月）出生的金命格外柔弱（火旺熔金），最怕日主本身又弱——调候须以水制火润局为先。
- 适用前提： 日主为金，生于巳午未月。
- 层级： 操作规则
- 流派： 调候法
- 反例边界： 金已得强根成势时，水多反泄金气，调候让位于旺衰；金水伤官格（身强金旺见水）反喜火炼，不以此论。

### TH-0004
- 典籍： 穷通宝鉴·论金
- 原文： 冬月之金，形寒性冷。木多则难施琢削之功，水盛而未免沉潜之患。
- 白话： 冬天（亥子丑月）出生的金命寒冷，需火暖局；此时木多水盛皆不宜，唯火（调候）为先。
- 适用前提： 日主为金，生于亥子丑月。
- 层级： 操作规则
- 流派： 调候法
- 反例边界： 冬金若已成金水相生润下之势（从革/润下格局），反以顺其寒势为吉，不可强取火逆局。

### SS-0001
- 典籍： 渊海子平·继善篇
- 原文： 伤官见官，为祸百端。
- 白话： 伤官与正官同见且无化解时，才华与规则的冲突会带来诸多波折。
- 适用前提： 伤官与正官均有力、无印星制伤或财星通关。
- 层级： 操作规则
- 流派： 子平通用
- 反例边界： 伤官伤尽（无官可伤）、或印制伤官护官、或金水伤官喜见官（冬金以官火调候）时，不以此断祸。

### SS-0002
- 典籍： 渊海子平·继善篇
- 原文： 食神有气胜财官。
- 白话： 食神健旺有力（日主有根、食神通根得生），其福气胜过财官。
- 适用前提： 日主身强有根，食神有力不遭枭印夺食。
- 层级： 操作规则
- 流派： 子平通用
- 反例边界： 枭神（偏印）贴身夺食、或食神过重泄身太过（身弱）时反为病，须弃此论。

### SS-0003
- 典籍： 滴天髓·何知章
- 原文： 何知其人富，财气通门户。
- 白话： 怎么看一个人富？财星之气在命局中流通有情（财有源、有护、日主担得起）。
- 适用前提： 财星与日主力量匹配（身财两停或有食伤通关）。
- 层级： 操作规则
- 流派： 旺衰法
- 反例边界： 财多身弱反为"富屋贫人"；从财格之富以势论，不以门户流通论。

### GJ-0002
- 典籍： 神峰通考·病药说
- 原文： 有病方为贵，无伤不是奇。格中如去病，财禄两相随。
- 白话： 命局有"病"（突出的缺陷）而有"药"（制衡之物）反而是好命；病被药去，富贵随之。
- 适用前提： 命局有明确之病，且有对应之药到位。
- 层级： 操作规则
- 流派： 病药法
- 反例边界： 病重药轻（药不足以制病）或药遭冲合失去作用时，不以此断贵；五行流通无病的平和命，不套病药说。

### GJ-0003
- 典籍： 滴天髓·从象
- 原文： 从得真者只论从，从神又有吉和凶。
- 白话： 真从格就按"从势"论命，顺从旺势之五行为喜、逆势为忌。
- 适用前提： 日主极弱无强根、无印比帮扶，势成一方。
- 层级： 操作规则
- 流派： 旺衰法
- 反例边界： 有一点强根或印星即"假从"，假从行运扶根时反破格，吉凶须细辨；从格最忌行帮身运（除非假从）。

### GJ-0004
- 典籍： 滴天髓·何知章
- 原文： 何知其人贵，官星有理会。
- 白话： 怎么看一个人贵？官星（事业地位之星）在命局中得到合理的配置（有财生、有印护、有制衡）。
- 适用前提： 官星清而不杂、日主能任。
- 层级： 操作规则
- 流派： 旺衰法
- 反例边界： 官杀混杂无制、身弱不能任官时反为压力与是非，不以此断贵。

### SH-0001
- 典籍： 三命通会·论天乙贵人
- 原文： 其神最尊贵，所至之处，一切凶煞隐然而避。
- 白话： 天乙是神煞中最尊贵的，命带天乙贵人在困境中易得有力者相助、逢凶化吉。
- 适用前提： 天乙贵人按日干查得（见 rules/3-神煞规则.md 同表）且不被冲空。
- 层级： 例证
- 流派： 神煞派
- 反例边界： 神煞为格局用神框架下的加减分项，贵人落空亡或为忌神时助力打折；不得脱离格局单凭神煞断吉凶。

### SH-0002
- 典籍： 滴天髓·地支
- 原文： 支神只以冲为重，刑与穿兮动不动。
- 白话： 地支关系中以"冲"的力量和影响最重，刑与害多数时候只是"扰动"，未必成患。
- 适用前提： 地支关系已由排盘脚本列出。
- 层级： 操作规则
- 流派： 旺衰法
- 竞合： DTS-0002（冲的胜败由旺衰定）——两卡并用：先按本卡定轻重，再按 DTS-0002 定胜负。
- 反例边界： 三刑齐全（如寅巳申全）力量亦重；冲有合解、或被冲之支为闲神时，冲害亦轻。

### YS-0001
- 典籍： 子平真诠·论行运
- 原文： 论运与看命无二法也。看命以四柱干支配月令之喜忌，而取运则又以运之干支配八字之喜忌。
- 白话： 看大运和看命局用同一套方法：以大运干支对照命局喜忌来定这段运程的顺逆。
- 适用前提： 命局喜忌（用神忌神）已定；大运干支与起运以排盘脚本为准。
- 层级： 核心论断
- 流派： 子平格局
- 反例边界： 用神会随大运流年变化（岁运引动改变力量对比），不可全程套用原局喜忌一成不变。

### YS-0002
- 典籍： 滴天髓·何知章
- 原文： 何知其人寿，性定元神厚。
- 白话： 心性安定、元气（日主根基）厚实的人，健康底子好。
- 适用前提： 日主有根不虚、五行不太偏枯。
- 层级： 例证
- 流派： 旺衰法
- 反例边界： **本技能严禁用于寿元推断**，仅作为"心态平和、养护根本有益健康"的养生方向旁证；涉及健康一律只建议注意养护，不断言疾病与寿数。

### ZPZQ-0001
- 典籍： 子平真诠·论用神成败救应
- 原文： 成中有败，必是带忌；败中有成，全凭救应。
- 白话： 格局看起来成了却层次不高，必是带了忌神；格局有败点却能转好，全靠救应之物——层次高低要看带忌与救应，不能成格即断贵。
- 适用前提： 格局已定，成格之物与忌神、救应之物可辨识。
- 层级： 核心论断
- 流派： 子平格局
- 反例边界： 救应之物本身被冲合则救应失效；忌轻且有制时"带忌"只略降层次，不据此否定成格。

### QTBJ-0001
- 典籍： 穷通宝鉴·五行总论
- 原文： 金赖土生，土多金埋；土赖火生，火多土焦；火赖木生，木多火炽；木赖水生，水多木漂；水赖金生，金多水浊。
- 白话： 生扶者过重反而成害（母旺灭子）：土生金但土太厚埋金、火生土但火太旺焦土……五行生扶须恰到好处。
- 适用前提： 判断过旺之病与生扶是否过度时引用。
- 层级： 核心论断
- 流派： 调候法
- 反例边界： 身弱喜生扶者不以此论（生扶正是所需）；过旺之病还需看有无制泄之药（配合 GJ-0002 病药说）。

### DTS-0001
- 典籍： 滴天髓·何知章
- 原文： 何知其人凶，忌神辗转攻。
- 白话： 怎么看一个人多困顿？忌神多且连环攻身（无制无化）——忌神辗转克伐为凶，行运再引动更甚。
- 适用前提： 忌神与制化之力对比明确。
- 层级： 操作规则
- 流派： 旺衰法
- 反例边界： 忌神有制有化则凶减；事件级结论仍需孤证不立（双证据），健康类只到养护层面。

### DTS-0002
- 典籍： 滴天髓·地支
- 原文： 旺者冲衰衰者拔，衰神冲旺旺神发。
- 白话： 冲的胜负由旺衰定：旺方冲衰方，衰方连根拔起；衰方去冲旺方，反而激发出旺方的力量。
- 适用前提： 地支关系已由排盘脚本列出，双方旺衰可判（配合 rules/6-地支关系.md 力量级总纲）。
- 层级： 操作规则
- 流派： 旺衰法
- 竞合： SH-0002（支神只以冲为重）——两卡并用：先按 SH-0002 定轻重，再按本卡定胜负。
- 反例边界： 冲有合解（贪合忘冲）、被冲者为闲神时力量轻；旺衰难判时不下胜负结论。

### DTS-0003
- 典籍： 滴天髓（任铁樵注本）
- 原文： 众煞猖狂，一仁可化。
- 白话： 七杀众多猖狂无制时，一个有力的印星（仁）可以化杀生身，转压力为助力——杀印相生之理。
- 适用前提： 杀重身弱，且印星有力、未被财克破。
- 层级： 操作规则
- 流派： 旺衰法
- 反例边界： 印星被财星克破（坏印）则"一仁"不成立；杀轻印重反成印多埋身，取用另论。
