# 十神详解 (Ten Gods)

十神是八字命理中描述日主（Day Master）与其他干支关系的符号系统。十神本身**无绝对吉凶**，其性质取决于日主强弱和命局整体配置。

## 十神在不同四柱位置的含义

同一十神出现在年柱、月柱、日柱或时柱，含义有本质区别。

| 十神 | 年柱 | 月柱 | 日支（坐支） | 时柱 |
| :--- | :--- | :--- | :--- | :--- |
| **比肩** | 祖上根基一般 | 兄弟朋友多 | 配偶独立好胜 | 晚年自力更生 |
| **劫财** | 祖业难守 | 兄弟姐妹不睦 | 配偶易争执、破财 | 晚年防财务纠纷 |
| **食神** | 祖上温和宽厚 | 青年才华展露 | 配偶温厚顾家 | 晚年安逸享福 |
| **伤官** | 幼年聪颖叛逆 | 青年锋芒毕露 | 配偶貌美挑剔（男女皆需注意感情） | 晚年多才多艺 |
| **偏财** | 祖上经商或慷慨 | 青年偏财运佳 | 配偶豪爽（男命易有桃花） | 晚年意外之财 |
| **正财** | 祖辈勤俭持家 | 青年正财运佳 | 配偶贤惠务实（男命得贤妻） | 晚年积蓄丰足 |
| **七杀** | 幼年体弱或压力大 | 青年魄力强、竞争激烈 | 配偶个性刚强（女命易配权威型配偶） | 晚年事业心不减 |
| **正官** | 祖上有名望 | 青年循规蹈矩 | 配偶端庄正派（女命得良夫） | 晚年受人尊敬 |
| **偏印** | 祖上特殊技艺 | 青年思维独特 | 配偶内向敏感 | 晚年清静独处 |
| **正印** | 祖上积德庇佑 | 青年学业顺利 | 配偶仁慈包容（男命得贤内助） | 晚年安逸有靠 |

## 生克关系

### 相生链
```
比劫 ──生──→ 食伤 ──生──→ 财星 ──生──→ 官杀 ──生──→ 印星 ──生──→ 比劫
```
- 比劫生食伤：同伴/自身产生才华与表达
- 食伤生财星：才华转化为财富
- 财星生官杀：财富滋养地位与权力
- 官杀生印星：压力转化为智慧与保护
- 印星生比劫：学识滋养自身与同伴

### 相克链
```
比劫 ──克──→ 财星 ──克──→ 印星 ──克──→ 食伤 ──克──→ 官杀 ──克──→ 比劫
```
- 比劫克财星：同伴/自身损耗财富
- 财星克印星：财富侵蚀学习与庇护
- 印星克食伤：保守压制才华发挥
- 食伤克官杀：自由与规则对抗
- 官杀克比劫：规则约束自身与同伴

## 经典格局速查

以下格局是八字论命中判断层次高低的核心依据：

### 贵格（主事业、地位）

| 格局名 | 组合 | 成格条件 | 含义 |
| :--- | :--- | :--- | :--- |
| **食神制杀** | 食神 + 七杀 | 日主有根、食神力能制杀 | 以智慧化解压力，武贵之格，适合管理、军警、技术领导 |
| **杀印相生** | 七杀 + 正印/偏印 | 杀生印、印生身，流通有情 | 压力转智慧，权贵之格，适合体制内晋升 |
| **伤官配印** | 伤官 + 正印 | 伤官有制而不泄身太过 | 才华有约束，文贵之格，适合学者、作家 |
| **官印相生** | 正官 + 正印/偏印 | 官印双清、日主有根 | 正统贵气，适合公务员、教育界 |
| **食伤泄秀** | 食神/伤官旺 + 身强 | 身强且食伤有力 | 聪明才智充分发挥，适宜文艺、技术 |

### 富格（主财富）

| 格局名 | 组合 | 成格条件 | 含义 |
| :--- | :--- | :--- | :--- |
| **食伤生财** | 食神/伤官 + 正财/偏财 | 流通无阻、日主有根 | 靠技艺智慧赚钱，富格首选 |
| **财官相生** | 正财/偏财 + 正官 | 财生官、官护财 | 财富与地位相互成就 |
| **从财格** | 满盘财星、日主无根 | 不可见比劫印星破格 | 弃命从财，大富（忌破格） |

### 特殊格局

| 格局名 | 识别标志 | 要点 |
| :--- | :--- | :--- |
| **从强/从旺** | 满盘印比、日主极强、无官杀克制 | 顺其旺势为吉，不可逆 |
| **从杀格** | 满盘官杀、日主无根无印 | 弃命从杀，权贵 |

## 用神体系（核心判断法）

用神是平衡命局的关键五行，是判断运势吉凶的根本依据。

### 五大用神类型

| 类型 | 适用场景 | 选取方法 | 示例 |
| :--- | :--- | :--- | :--- |
| **扶抑** | 身强或身弱需平衡 | 身强取克泄耗（官杀/食伤/财）、身弱取生扶（印/比劫） | 身强火命 → 用水（官杀）、金（财）、土（食伤） |
| **调候** | 冬夏出生需调温湿度 | 冬生喜火暖局、夏生喜水润燥、湿土月用火、燥土月用水 | 壬水生于子月 → 急需丙火暖局 |
| **通关** | 两种五行激烈相战 | 取能沟通两者的五行 | 金木相战 → 用水通关（金生水、水生木） |
| **病药** | 某一五行过旺为病 | 取能克制/泄耗该五行的为药 | 木过旺为病 → 取金制木或取火泄木 |
| **顺势** | 从格/化格等特殊格局 | 顺应旺势，不逆其势 | 从强格喜印比、忌官杀 |

### 用神判断流程

1. **先看调候**：生于亥子丑月（冬）急需火暖局、生于巳午未月（夏）急需水润局
2. **再定强弱**：得令（月支生扶）、得地（地支有根）、得势（天干多见同类）
3. **后选扶抑**：身强取克泄耗、身弱取生扶
4. **兼顾通关**：若有金木交战、火金交战等，用水或土通关
5. **终定格局**：检查是否成从格、化格等特殊格局

## 十神心性深度

### 身强时的表现
- **比劫强**：自信独立，但固执冲动，易破财、克妻（男命需注意）
- **食伤强**：才华横溢，但锋芒过露，易得罪人
- **财星强**：财运亨通，但若财多身弱反成负担
- **官杀强**：事业心强，但压力大、易焦虑
- **印星强**：学识渊博保护周全，但若印多身强反成依赖

### 身弱时的表现
- **比劫弱**：缺乏自信，需要依靠他人
- **食伤弱而官杀强**：有创意受压制感
- **财星强而身弱**："富屋贫人"——机会多但抓不住
- **官杀强而身弱**：小人多、压力大、健康需警惕
- **印星弱**：学习能力受制、缺乏庇护

## 分析禁忌

1. 不可仅凭单一十神断吉凶——必须结合日主强弱和全局配置
2. 同一十神在不同柱位含义不同——必须区分年月日时
3. 格局成败比十神多少更重要——一个成格的好八字胜过十神俱全的平庸八字
4. 用神不是固定的——大运流年变化可能改变用神
