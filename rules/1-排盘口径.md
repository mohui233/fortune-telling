# 排盘口径

## 唯一事实源协议

1. 四柱、藏干、十神、纳音、旬空、神煞、刑冲合害、大运顺逆与起运、节气时刻，一律以 `scripts/pai_pan.py` 的 stdout 为准。
2. **禁止**：口算干支、凭记忆万年历推柱、自行推大运后覆盖脚本、引用脚本未输出的神煞或关系。
3. 用户提供的专业排盘经确认屏核对后可作为替代事实源（标记"用户已确认排盘"），不与脚本结果混用；两者冲突时请用户裁决，不自行取舍。
4. 脚本或文档需要变更口径时：同步修改本文件、`scripts/pai_pan.py` 头部锚点注释、`rules/3-神煞规则.md`（神煞表）与 `tests/test_pai_pan.py`（黄金用例），四处一处不动即视为未变更。

## 固定口径（锚点表，与脚本 docstring 一致）

| 项 | 口径 | 黄金锚点 |
| :--- | :--- | :--- |
| 时区 | 北京时间 UTC+8，不用本机时区 | — |
| 年柱分界 | 当年立春精确时刻（非正月初一、非 2 月 4 日零点） | 1990-02-03 10:00 → 年柱**己巳**；1990-02-04 11:00（立春 10:14 后）→ **庚午** |
| 月柱分界 | 十二「节」精确时刻（立春/惊蛰/清明/立夏/芒种/小暑/立秋/白露/寒露/立冬/大雪/小寒），中气不换月 | 1990-05-15（立夏后芒种前）→ **辛巳**月 |
| 晚子时 | 子平口径：23:00 起日柱、时柱均按次日 | 1990-05-15 23:30 → 庚午/**辛巳**/**辛巳**/戊子 |
| 早子时 | 00:00-01:00 日柱用当日，时柱按当日日干五鼠遁 | 1990-05-15 00:30 → 庚午/辛巳/**庚辰**/丙子 |
| 基准盘 | — | 1990-05-15 12:00 男 → 庚午/辛巳/庚辰/壬午；农历一九九〇年四月廿一同盘 |
| 大运方向 | 阳年男/阴年女顺排；阴年男/阳年女逆排；从月柱下一柱（顺）或上一柱（逆）起 | 1991-08-15 男（辛未阴年）→ 逆排，首步**乙未** |
| 起运 | 引擎按「出生到节气天数 ÷ 3」精算，输出年/月 | 1990-05-15 男 → 出生后 7 年 3 个月 |
| 旬空 | 日柱所在旬 | 庚辰日（甲戌旬）→ 空申酉 |

引擎：`scripts/vendor/lunar_python`（6tail lunar-python，MIT）。回归验证：`python tests/test_pai_pan.py`（含与独立实现 jinchenma94/bazi-skill 的 18 例交叉验证）。

## 警告分级处置

| 级别 | 触发 | 处置 |
| :--- | :--- | :--- |
| 复核级 | 距节气/立春边界 ≤2 小时 | 严格采用脚本结果；报告显著提示"节气交界，建议与专业排盘工具复核" |
| 提示级 | 距节气交界 ≤24 小时；夜子时/早子时口径 | 采用脚本结果，向用户说明口径与风险 |
| 追问级 | 距时辰整点边界 ≤15 分钟；经度修正后跨时支 | **先问后断**：确认时点可靠性、钟表时间 vs 真太阳时；未确认前时柱相关结论标"存疑" |
| 缺省级 | 时辰未知 → 六字盘；性别未知 → 不排大运 | 如实缺省并说明影响（时柱藏干十神、神煞、大运起运缺失） |

## 真太阳时档位

- **档位0（默认）**：钟表时间（北京时间），不做修正。
- **档位1（`--lon` 提供出生地东经经度时）**：输出量化警示——经度修正 `(经度-120)×4` 分钟 + 均时差（NOAA 近似式，全年约 -14~+16 分钟）合计值；**不改柱**。修正后跨时支 → 追问用户确认口径，确认修正后请用户走"用户已确认排盘"通道提供四柱。
- **档位2（完全均时差校正）不实现**：需要完整校正时，请用户以专业排盘工具计算后走"用户已确认排盘"通道。
- 两种口径落不同时支时，双盘并列请用户确认，不得静默取一；真太阳时的一切计算在脚本内完成，禁止模型自行换算时支。

## 时辰模糊映射（用户只给描述时先映射再追问）

| 用户描述 | 可能时辰 | 处理 |
| :--- | :--- | :--- |
| "天还没亮" | 寅（3-5）/ 卯（5-7） | 列出候选问用户 |
| "早饭前后" | 辰（7-9）/ 巳（9-11） | 同上 |
| "中午" | 午（11-13） | 直接采用，时柱结论按午时 |
| "傍晚/天快黑" | 酉（17-19）/ 戌（19-21） | 列出候选问用户 |
| "半夜" | 子（23-1）/ 丑（1-3） | 列出候选并说明早晚子时口径差异 |
| 只知道时辰名（如"午时"） | 取该时辰中点（如 12:00） | 采用后提示"按该时辰中点计算，时柱可靠、日柱以是否跨午夜为准" |

时辰名缺钟点且涉子时（23:00-01:00 跨日界）时，必须追问钟点或告知按早子时处理的口径。

> 时辰名→钟点的换算由脚本 `--shichen` 参数执行（时辰中点，子时按 00:00 早子时口径并出警告），**禁止模型自行换算**；仅提供自然语言描述时，先按上表映射为时辰名再传脚本。

## 已故命主

命主已故时收集去世年份，脚本 `--deceased-year` 截断流年（不列身后年份），默认在世、不主动问（话术见 `commands/10-信息收集与排盘.md`）。为已故命主解读时语气庄重，只作生平倾向性回顾，不作"来年运势"类表述。

## 排盘错误的不可逆性说明

排盘是全部下游分析的事实基础：柱错则格局、用神、大运全错。因此宁可多一次确认，不可少一次追问；宁可标注存疑，不可含糊带过。
