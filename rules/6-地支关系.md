# 地支关系 (Branch Relations)

> 命盘中存在哪些关系以 `scripts/pai_pan.py` 输出的「刑冲合害」段为准（本表与脚本内建表同口径）；本文件规定**如何解读**。大运、流年引动的关系同理——只解释脚本列出的，不得凭记忆新增。

## 力量级总纲（先定轻重，再谈吉凶）

**冲最重，合次之，刑害为扰动**（引用卡片 SH-0002：支神只以冲为重，刑与穿兮动不动）。具体顺序：

| 关系 | 力量 | 性质 |
| :--- | :--- | :--- |
| 三合局全 | 极强 | 该五行力量爆发（脚本标"力量极大"） |
| 三会方全 | 极强 | 同类五行集结，势头最顺 |
| 六冲 | 强 | 冲突、变动、不稳定——最优先看 |
| 六合 | 中 | 和谐、牵绊（合能解冲：贪合忘冲） |
| 半合（含旺神） | 中 | 合力减半，待流年补全则爆发 |
| 相刑 / 自刑 | 弱-中 | 摩擦、内耗（三刑齐全则升级为重） |
| 相害 | 弱 | 暗中破坏、误会 |
| 天干五合 | 中 | 牵绊亲和；合而不化（需月令与全局佐断，脚本默认此口径） |

## 六合（和谐、合作、牵绊）

子丑合、寅亥合、卯戌合、辰酉合、巳申合、午未合。

- 解读：合为"绊"——被合之物力量减弱、行动受限；合住用神 → 好事打折，合住忌神 → 坏事减损。
- 合化条件：月令为化神五行且全局配合方论化，否则合而不化（只论牵绊，不论化气）。

## 三合局与半合（力量强大、方向一致）

- 申子辰合水局、寅午戌合火局、亥卯未合木局、巳酉丑合金局。
- 三字俱全：该五行力量爆发（脚本标"力量极大"），吉凶随该五行是喜是忌。
- 半合：两支且**旺神（子午卯酉）在位**方论（如申子、子辰可论半合；申辰无子不论）——与脚本口径一致；待流年补齐第三支则成局爆发。
- 三会方：寅卯辰会东方木、巳午未会南方火、申酉戌会西方金、亥子丑会北方水——同类连气，力量次于三合全但势顺。

## 六冲（冲突、变动、不稳定——最优先看）

子午冲、丑未冲、寅申冲、卯酉冲、辰戌冲、巳亥冲。

| 冲在 | 宫位含义 |
| :--- | :--- |
| 年支 | 祖上根基、早年环境动荡，或与长辈缘分变动 |
| 月支 | 青年时期大变动；月令提纲被冲 → 格局力量受损，成败打折 |
| 日支 | **夫妻宫动荡**——婚恋关系变动信号，只提示"需用心经营"，不断言离散 |
| 时支 | 子女缘分或晚年不稳 |

- 冲之对象看十神：冲财星 → 财来财去；冲官星 → 事业变动；冲印星 → 学业居所变动。冲的是用神所在宫位则减分，冲忌神则反有松绑之象。
- 合可解冲：被冲两方之一逢合，冲力大减（贪合忘冲）。
- 大运流年地支冲命局 → 引动（该宫位/十神领域起变化），见 `commands/30-大运流年分析.md`。

## 相刑（摩擦、纠纷、隐忧）

- 寅巳申三刑（无恩之刑）：利益之争、恩将仇报类纠纷；
- 丑戌未三刑（恃势之刑）：势力倾轧、官非口舌；
- 子卯刑（无礼之刑）：礼数冲突、晚辈/情感摩擦；
- 自刑：辰辰、午午、酉酉、亥亥——自我纠结、内心反复、自我消耗。
- 两两相见为轻度刑害（扰动）；**三刑齐全**力量升级为重（近于冲）。

## 相害（暗中破坏、误会）

子未害、丑午害、寅巳害、卯辰害、申亥害、酉戌害。

- 解读：明面上无冲突、暗地里受损，主误会、暗伤、小人暗算倾向——措辞中性化（"注意沟通透明"而非"必遭暗算"）。

## 天干五合

甲己合土、乙庚合金、丙辛合水、丁壬合木、戊癸合火。

- 解读同六合：牵绊亲和、减力；合而不化（脚本默认口径），化气需月令化神当令且全局不背。
- 合在年月（长辈缘）、日时（自身与配偶/子女缘）；日干被合 → 自身主见易受牵动。

## 解读纪律

1. 只解读脚本输出的关系；大运流年引动以脚本 `## 流年要点` 标记为准，不自行加减。
2. 先定轻重（力量级表），再结合宫位与十神解读，最后落建设性建议——冲刑害只说"动荡/需经营/注意沟通"，严禁"必离必破"式恐吓。
3. 半合缺旺神、三刑不全、自刑单现等弱关系，点到即止，不夸大。
4. 关系多而不乱是常态：优先解读冲、三合全会、日支与月令上的关系，其余一笔带过。
