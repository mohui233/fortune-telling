# 证据与引用规则

## 事实来源

命盘事实只能来自三个通道，通道之外不得引入：

1. **排盘脚本 stdout**（默认通道）：四柱、藏干十神、纳音、旬空、神煞、关系、大运、节气。
2. **用户已确认排盘**：用户提供的专业排盘，经确认屏核对（含用户改柱）后成为唯一事实。
3. **用户明确输入**：出生信息、已知历史事件（用于校准）、出生地。

对话历史里的模糊提及（"我好像是 95 年生的"）不足以支撑事实，须确认。多个信息源冲突时请用户裁决，不得静默取一。

## 结论标注协议（三层依据）

每条结构性结论在成稿时必须可回溯，正文结论后跟依据，依据分三层：

1. **命盘依据（必填）**：柱位 + 干支 + 十神/神煞/关系。例："性格独立有决断（依据：日柱庚申，日坐专禄）"。
2. **典籍依据（可选）**：`rules/典籍卡片.md` 中实际存在的卡片 ID。只准引用存在的卡片，引用时保持原意并解释含义。
3. **无据标注（兜底）**：无典籍可引时写"无典籍条文支撑"——与真实引用同等合法，**不得**编造卡片、拼凑书名或把经验推论伪装成典籍论断。

纯书名装饰性引用（"《滴天髓》云人生无常"之类无具体条文）一律删除。

## 事实句与推论句分离

- **命盘事实句**：干支、十神、神煞、关系、大运起止——只能来自脚本输出，逐字一致。
- **解释推论句**：基于事实的分析判断——必须建立在已列事实之上，不得夹带新的命盘事实。
- **用户自述句**：校准反馈、已发生事件——标注"用户自述"，与命盘依据分开，不冒充命盘证据。

## 孤证不立

事件级判断（婚变、转行、破财、健康波动、重大变动年）至少需要**两条独立命盘证据**（如：流年天克地冲 + 夫妻宫逢冲；忌神大运 + 流年引动）。只有一条证据时：

- 降级为"倾向提示"（"存在变动倾向，具体取决于个人选择与环境"）；
- 或删除。

同一事实拆成两条（日支被冲 + 冲在婚姻宫）不算两条独立证据。

## 古籍引用纪律

1. 只引 `rules/典籍卡片.md` 中存在的卡片；卡片六字段齐备（典籍/原文/白话/适用前提/层级/反例边界）才可被引。
2. 引用必须核对卡片的**适用前提**与**反例边界**：前提不满足或落在反例边界内时，该卡片不得支撑当前结论（例：YL-0002 月令取用神，但月令被合化或不成格时不可硬套——卡片反例边界已注明）。
3. 卡片之间存在**竞合**时（如 YL-0002 月令优先 vs WS-0001 衰旺优先），须按 `rules/4-解盘原则.md` 的层级裁决并可在报告中并存表述（"格局法看……旺衰法看……"），禁止静默取一。
4. 原文以通行整理本为准，引用保留原意；白话为自撰释义。
5. 引用层级为"存疑"的卡片只能作旁证，不得独立支撑结论。

## 裁决优先级

不同来源的证据相互冲突时（如两张卡片竞合、用户自述与命盘显示相反），按以下顺序裁决，禁止静默取一；裁决结果与理由写入依据索引：

1. **脚本事实**（排盘输出中的干支、十神、神煞、关系、大运——最高，不可被任何解读推翻）
2. **用户确认事实**（用户确认屏改动、用户自述的历史事件——高于典籍推论）
3. **典籍卡片**（核心论断 ＞ 操作规则 ＞ 例证 ＞ 存疑；同级竞合在报告中并存表述，不硬取一边）
4. **方法适配与措辞偏好**（流派取舍见 `rules/7-流派分歧与取舍.md`；叙事偏好只影响表达不影响事实）

## 缺证据处理

信息不足时如实说明缺口（"时辰未知，以下仅就六字论命"），不得编造、不得用推测顶替。命理推断本身有不确定性——**不确定性要保留（标注存疑），不得隐藏或伪装成确定**。
