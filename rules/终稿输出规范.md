# 终稿输出规范

## 报告结构（全流程模式）

1. **命造总评**：一句话定性（格局+层次+适配方向），后附**计算元数据块**与排盘事实表（四柱/藏干十神/旬空/大运方向与起运，从确认屏复制）与警告处置说明。

**计算元数据块模板**（紧跟在命造总评后，固定字段，保证可回溯）：

```markdown
| 元数据 | 值 |
| :--- | :--- |
| 排盘引擎 | scripts/pai_pan.py（vendor lunar_python 6tail） |
| 口径 | 北京时间；立春分年、十二节分月；晚子时按子平口径（日柱时柱用次日） |
| 真太阳时 | 档位0 钟表时间 / 档位1 经度+均时差量化警示（不改柱） |
| 排盘事实来源 | 脚本输出 / 用户已确认排盘（含改柱） |
| 警告处置 | 已逐条处置（复核级 X 条 / 追问级 X 条 / 无） |
| 已故信息 | 无 / 已故年份（流年截断） |
```
2. **性格深度剖析**：显性性格、隐性心理、优势与注意点。
3. **事业财富规划**：格局倾向贵/富（引 GJ-0004/SS-0003 时核对反例边界）、适合行业与职场建议、财运起伏与大运配合。
4. **情感婚姻建议**：日支夫妻宫分析、男命看财星/女命看官杀、择偶方向与相处之道；只给倾向与建议，不断婚配成败。
5. **健康养生**：五行偏枯对应部位、养护方向；只到"注意养护"，不做疾病断言（YS-0002 反例边界）。
6. **近期运势预警**：未来 1-3 年逐年机遇与挑战，含脚本 ⚠ 标记（岁运并临/天克地冲）的提示。
7. **知命造命建议**：用神喜忌对应的颜色、方位、行业、行为与心态调整，给可落地的选项而非唯一答案。
8. **依据索引**：尾注表，格式见 `commands/40-成稿与依据索引.md`，无空表通过。
9. **免责声明**：固定文案，一字不省。

专题追问模式输出：直答（结论+依据）→ 1-2 段展开 → 精简依据 → 免责声明。

## 章节口径

- 每章开头一句结论先行，依据随后；引用古籍必须解释含义。
- 指出问题的章节必须给出建设性建议（化解方向），"只判不治"的章节退回补写。
- 命盘事实与解释推论分开：事实只在排盘事实表与依据索引出现，分析章节写推论并回指依据。

## 措辞规范

| 禁用 | 替代 |
| :--- | :--- |
| 大凶、必死、家破人亡、克夫克妻 | 重大挑战、需谨慎应对的时期 |
| 注定、这辈子就是 | 命盘呈现的倾向、先天禀赋偏向 |
| 你必须/你应该辞职（结婚/离婚） | 换环境可能对您更有利，建议您结合现实综合考量 |
| 有血光之灾 | 需注意安全、控制急躁情绪 |

- 古代术语首次出现给现代翻译（对照 `rules/4-解盘原则.md` 现代化对照表）。
- 语气温暖共情；对不确定处保留"存疑"标注，不伪装确定。
