# 翻车预防清单

> 每条：错误表现 → 正确做法。从真实翻车模式中沉淀，持续补充。

## 排盘翻车（错了则后面全错，最优先扫）

| 翻车表现 | 正确做法 |
| :--- | :--- |
| 口算干支、凭记忆万年历推四柱/流年 | 一律先跑 `scripts/pai_pan.py`；流年补查重跑加 `--liunian` |
| 立春前出生年柱按公历年取 | 以立春精确时刻分界（锚点：1990-02-03 10:00 年柱己巳） |
| 2 月出生就当"寅月" | 月柱以十二节时刻分界，2 月上旬多仍为丑月，看脚本结果 |
| 23:00 后日柱仍用当天 | 子平口径：日柱、时柱均按次日（夜子时标记） |
| 时辰模糊描述直接猜 | 先查 `rules/1-排盘口径.md` 模糊映射表，候选多于一个就追问 |
| 真太阳时"顺手"修正时柱 | 默认钟表时间；经度修正只做边界警示，跨时支必须问用户 |
| 用户已给专业排盘又重新计算覆盖 | 用户确认排盘即事实，除非用户要求复核 |
| 漏问性别就排大运 | 性别决定顺逆，缺则不排大运并明示 |
| 农历闰月当普通月换算 | 用 `--calendar lunar --leap`，换算结果以脚本为准 |
| 脚本警告被静默忽略 | 逐条按 `rules/1-排盘口径.md` 处置表处理并体现在报告 |
| 改了脚本或神煞表只改一处 | 口径四处同步：脚本、`rules/1-排盘口径.md`、`rules/3-神煞规则.md`、黄金测试 |

## 解读翻车

| 翻车表现 | 正确做法 |
| :--- | :--- |
| 未定格局先断流年吉凶 | 层级递进：格局 → 强弱 → 用神 → 十神 → 神煞 → 大运流年 |
| 看到吉神就断大吉、凶煞就恐吓 | 神煞是加减分项，格局用神为本（SH-0001 反例边界） |
| 单凭一个十神断性格/事业 | 十神须结合柱位、强弱、组合综合论 |
| 从格认定宽松 | 有一点强根或印星即不从，从格从严（GJ-0003 反例边界） |
| 用神与格局强弱结论打架 | 回到格局复查，不得为"好听"强行取用 |
| 流年只看地支不合参天干十神 | 干支十神一起论（脚本流年段已标注十神） |
| 岁运并临、天克地冲漏看或滥用 | 以脚本 ⚠ 标记为准，标记了才提示，且只说"变动可能性大" |
| 引用典籍凭印象编条文 | 只引 `rules/典籍卡片.md` 存在的卡片，核对适用前提与反例边界 |
| 事件级判断只有一条证据就下断 | 孤证不立：两条独立命盘证据，否则降级为倾向提示 |
| 校准反馈不对就改排盘 | 排盘是事实不可倒推改；只调整倾向性表述强度 |

## 输出翻车

| 翻车表现 | 正确做法 |
| :--- | :--- |
| 长报告没经过排盘确认屏 | 排盘确认屏先行，用户确认后再展开 |
| 报告无依据索引 | 尾注依据索引表必附，无空表通过 |
| 装饰性书名引用（"古人云"） | 删除或替换为具体卡片 ID |
| 健康/婚恋/投资断言无免责 | 对应章节附温和建议 + 结尾完整免责声明 |
| 报告缺"AI 辅助生成，仅供参考" | 免责声明固定收尾，一字不省 |
| 用户自述与命盘依据混写 | 自述标"用户自述"，与命盘依据分列 |
| 内部产物（脚本命令行、候选清单）泄漏进报告 | 终稿只保留用户可读内容 |
| 用"大凶/克夫克妻/注定"等词 | 换中性词：挑战、波动、需用心经营（对照 `rules/4-解盘原则.md`） |
