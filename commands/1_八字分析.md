# 八字分析 (Bazi Analysis)

## 步骤一：获取命盘信息

1. **检查输入**: 判断用户是否直接提供了“四柱干支”或“大运信息”。
   - 若用户已提供完整排盘信息（如：“甲子年 丙寅月...”），则**直接使用用户数据**，跳过排盘步骤。
2. **检查工具 (若需排盘)**: 
   - 若用户仅提供了出生时间，检查环境中是否存在 `mingpan` MCP 工具（如 `bazi_basic`）。
3. **执行排盘**:
   - **Mode A (MCP)**: 调用 `bazi_basic(year, month, day, hour)` 获取精准结果。
   - **Mode B (估算)**: 若无 MCP 工具，根据用户提供的出生时间，**自行推算**干支。
     - *警告*: 必须在输出开头显著提示：“因未连接专业排盘工具，节气交接时刻可能存在误差，建议核对。”
   - **必需信息**: 四柱（年柱、月柱、日柱、时柱）、藏干、空亡。

## 步骤二：格局判断

1. **定日主**: 确定日干（Day Master）及其五行属性。
2. **定月令**: 检查月支对日干的生克关系，判断得令、失令。
3. **定强弱**: 综合得地（坐支）、得势（其他干支），判断日主身强还是身弱。
   - 参考 `skills/1_十神详解.md` 中的“强弱平衡”。

## 步骤三：神煞分析

1. **查神煞**: 根据 `skills/2_神煞规则.md`，查找命盘中的吉神与凶神。
2. **重点关注**: 天乙贵人（是否有贵人运）、桃花（异性缘）、驿马（变动）。

## 步骤四：综合解读

1. **性格特征**: 结合十神心性（如食神主温和，七杀主急躁）与五行强弱进行描述。
2. **事业财运**: 分析财星（正偏财）与官杀（正偏官）的力量与组合。
3. **输出报告**: 按照 `skills/3_解盘原则.md` 的要求生成报告。

## 示例输出

```markdown
### 八字排盘结果
- **年柱**: 甲子 [海中金]
- **月柱**: 丙寅 [炉中火]
- **日柱**: 庚申 [石榴木]
- **时柱**: 辛巳 [白蜡金]

### 深度分析
1. **五行强弱**: 日主庚金生于寅月，失令...
2. **性格特征**: 为人讲义气，但有时过于冲动（依据：比劫过旺）...
3. **神煞**: 命带驿马，适合异地发展...
```
