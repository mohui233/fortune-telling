# 信息收集与排盘

## 必采信息（缺一项先问，一次最多 3 个问题，不猜）

| 项 | 要求 | 缺省处理 |
| :--- | :--- | :--- |
| 出生日期 | 公历或农历均可，必须明确是哪一种 | 未明确阴阳历时：默认按**阳历**处理，并在输出中显著标注"默认阳历，如有误请告知" |
| 出生时辰 | 钟点（HH:MM 最佳）；或时辰名（子丑寅…，脚本 `--shichen` 参数）；或自然语言描述（见 `rules/1-排盘口径.md` 模糊映射表） | 完全未知：排六字盘，明确告知时柱、大运缺失的影响，追问后可补 |
| 性别 | 男/女 | 未知：不排大运，明确告知 |
| 出生地经度 | 可选，用于真太阳时边界警示 | 缺省按钟表时间（口径见 `rules/1-排盘口径.md`） |
| 已故信息 | 仅当命主已故时收集去世年份（默认在世，**不主动问**） | 已故：脚本 `--deceased-year` 截断流年，不列身后年份 |
| 已有排盘 | 可选：用户提供的专业排盘（截图/文字四柱） | 有则优先用用户数据，跳过脚本排盘，但需走确认屏核对 |

用户提供的完整四柱（如"甲子年 丙寅月……"）标记为 `用户已确认排盘`，直接作为命盘事实使用，**不得重新计算覆盖**；仅当用户主动要求复核时才跑脚本比对。

## 运行排盘脚本

```bash
# 公历示例
python scripts/pai_pan.py --year 1995 --month 8 --day 15 --hour 14:30 --sex 男 --liunian 2026,2027
# 农历示例（闰月加 --leap）
python scripts/pai_pan.py --year 1990 --month 4 --day 21 --calendar lunar --hour 12:00 --sex 男
# 时辰未知 → 六字盘
python scripts/pai_pan.py --year 1990 --month 5 --day 15
```

- `--liunian` 填用户关心的年份或当前年份前后 1-3 年。
- `--json` 可获取结构化输出（适合程序化核对）。
- 脚本失败（退出码 2）时检查输入格式，不得改为人工推算。

## 警告处置表（逐条处理，不得静默忽略）

完整分级与依据见 `rules/1-排盘口径.md`。要点：

| 警告类型 | 处置 |
| :--- | :--- |
| 距节气/立春边界 ≤2 小时 | 严格采用脚本结果；在报告中提示"节气交界，建议与专业排盘工具复核" |
| 距节气交界 ≤24 小时 | 采用脚本结果；提示"出生时间记忆偏差可能换柱" |
| 距时辰整点边界 ≤15 分钟 / 经度修正跨时辰 | **追问用户**：确认采用钟表时间还是真太阳时、时点是否可靠；未确认前时柱结论标注"存疑" |
| 夜子时 / 早子时 | 按脚本口径（子平法，晚子时日柱时柱用次日），在报告中向用户说明口径 |
| 时辰未知 / 性别未知 | 如实缺省：六字盘 / 不排大运，明示影响范围 |

## 排盘确认屏（进入解读前必须输出）

```markdown
## 排盘结果确认
| 柱 | 干支 | 天干十神 | 藏干（十神） |
| 年 | 乙亥 | 正官 | 壬(偏财)、甲(七杀) |
| …… | | | |
- 日柱旬空：申酉
- 大运：逆排（阴年男命），出生后 2年5个月 起运
- ⚠ 警告：……（含处置说明）

以上排盘由确定性脚本计算。请确认是否正确？如与您掌握的排盘不一致，请指出，将以您确认的版本为准。
```

- 用户确认或未提出异议 → 进入解读阶段。
- 用户改柱 → 以修改后的排盘为唯一事实继续，**不重算、不回改**。
- 仅排盘模式到此输出 `20` 的精简分析（格局/强弱/用神定性）即可交付。

## 排盘后追问（全流程/专题模式，进入解读前）

**跳过条件**：用户不在场、异步/批量执行或用户已明确要"全流程报告"时，跳过本追问直接按模式执行，不得替用户假设当前问题。

确认屏通过后先问一句当前困扰，再进入 `20` 深读，**不得替用户假设当前问题**：

> 命盘已经排好了。您最近最想了解或最困扰的是哪方面？（事业、财运、感情、学业、健康、家庭，或其他具体事情——也可以说"都看看"）

- 用户点题 → 专题追问模式：`20`/`30` 对应章节优先展开。
- 用户"都看看" → 全流程模式：按 20 → 30 完整执行。
