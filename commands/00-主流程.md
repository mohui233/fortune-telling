# 主流程

## 第一步：模式识别（开工前先做，不跑全量再筛）

| 触发信号 | 模式 | 执行范围 |
| :--- | :--- | :--- |
| `/auto-fortune`、用户要"全方位运势/人生指南" | 全流程 | `10` → `20` → `30` → `40` → `50` |
| `/八字分析`、用户只要"排个盘/看看八字" | 仅排盘 | `10` → `20`（只做格局/强弱/用神定性，不做大运流年与长报告）→ `50` |
| 用户带着具体问题（感情/事业/财运/某年运势） | 专题追问 | `10`（已有命盘先确认复用，不重算）→ `20`/`30` 中对应章节 → `40` 精简版（问题直答+依据）→ `50` |
| 用户反馈"之前说的准/不准" | 校准 | `30` 的历史事件校准步骤，微调倾向性判断后复述结论 |
| 越界请求（择吉/合婚/紫微/起卦/占星等） | 声明边界 | 按 `SKILL.md` 范围与边界声明礼貌拒绝，建议专用工具，不即兴发挥 |

模式之间可切换：仅排盘模式交付后用户追问运势，补跑 30/40 即可，排盘事实复用。

## 第二步：按阶段执行

1. **排盘阶段**（`commands/10-信息收集与排盘.md`）：必采信息缺一项先问（一次最多 3 个问题，不猜）；跑 `scripts/pai_pan.py`；处置警告；输出排盘确认屏，等用户确认。用户确认后的排盘即本轮唯一命盘事实，后续阶段不得重算。
2. **解读阶段**（`commands/20-格局与用神分析.md`、`commands/30-大运流年分析.md`）：按递进层级展开，每条结论随手记命盘依据与典籍卡片 ID，供成稿阶段汇总。
3. **成稿核验阶段**（`commands/40-成稿与依据索引.md`、`commands/50-交付前质量核验.md`）：按模板成稿、生成依据索引，逐条过质量核验清单后交付。

## 长报告策略

- 中间分析不复述脚本全部输出，只引用与结论相关的柱位、十神、神煞、关系。
- 解读阶段不要提前套终稿文风，避免冗长；成稿阶段一次性整合。
- 用户只要一个问题的答案时，输出直答 + 依据 + 简短展开，不输出全量报告。

解读前后各扫一遍 `rules/翻车预防清单.md`。
