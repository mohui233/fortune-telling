# 智能运势分析 (Auto Fortune)

本指令整合八字排盘、格局分析、用神判断、大运推算和流年评估，提供全方位的运势报告。支持调用 `mingpan` MCP 进行精准计算，也支持在无环境模式下进行估算或手动输入。

## 输入规范
- **默认日历**：请明确告知用户输入的是 **阳历（公历）** 还是 **阴历（农历）**。
- **推荐格式**：`YYYY MM DD HH:mm [Gender] [Solar/Lunar]`
  - 示例 1：`1995 08 15 14:30 男 阳历`
  - 示例 2：`1995 07 20 14:30 男 阴历`（若未指定，默认为**阳历**）

## 执行流程

### 第一阶段：八字基础分析

1. **调用排盘**：
   - 优先尝试调用 `/八字分析` 获取完整八字排盘和基础分析。
   - 若用户未指定阴阳历，**必须先确认**，或默认为阳历并在结果中显著标注："*默认为阳历，如有误请告知*"。
2. **手动数据兼容**：若无法调用 MCP 且 AI 自行推算存疑，**主动询问**用户："能否提供您的八字排盘结果（截图或文字）？这将提高准确度。"
3. **提取关键信息**：日主强弱、格局类型、用神、忌神（参考 `rules/十神详解.md` 用神体系）。

### 第二阶段：大运推算与分析

#### 2.1 排大运规则
1. **起运规则**：
   - 阳年男命、阴年女命 → 顺排大运
   - 阴年男命、阳年女命 → 逆排大运
   - 阳年：年干为甲、丙、戊、庚、壬
   - 阴年：年干为乙、丁、己、辛、癸
2. **排运方法**：
   - 若有 MCP：调用 `bazi_dayun`。
   - **若无 MCP**：根据规则推算起运数与大运干支。
     - 从月柱出发，顺排或逆排
     - **强烈建议**用户补充大运信息（如："我 4 岁起运，目前在 辛酉 大运"）。

#### 2.2 大运与命局互动分析
1. **大运是好运还是坏运**：
   - 大运干支为用神 → 十年好运、发展期
   - 大运干支为忌神 → 十年低迷、考验期
   - 大运干支为用神但被命局合化 → 好运打折扣
   - 大运干支为忌神但被命局克制 → 凶中有救
2. **重点判断项**：
   - 当前大运对日主是生扶还是克泄耗
   - 大运是否引动命局的刑冲合害（如大运地支与日支相冲则婚姻宫动）
   - 大运与命局是否构成三合三会（力量极大）
3. **起运前的大运**：按月柱干支论，不分顺逆。

### 第三阶段：流年评估（命局+大运+流年 三层互动）

#### 3.1 流年判断规则

流年吉凶由命局、大运、流年三者的五行力量对比决定：

| 流年角色 | 对命局影响 | 判断 |
| :--- | :--- | :--- |
| **用神出现** | 流年为命局用神 | **吉年**——机会、收获、转机 |
| **忌神出现** | 流年为命局忌神 | **凶年**——挑战、压力、波折 |
| **用神被合/冲** | 流年合走或冲走用神 | 好事变坏事 |
| **忌神被合/冲** | 流年合走或冲走忌神 | 坏事变好事 |
| **岁运并临** | 大运与流年干支相同 | 力量加倍，吉则大吉、凶则大凶 |
| **天克地冲** | 流年与命局日柱天克地冲 | 重大变动年（婚变、换工作、搬家） |
| **三合三会** | 流年引动命局或大运的三合三会 | 该五行力量爆发 |

#### 3.2 流年十神判断（结合 `rules/十神详解.md`）
- 流年遇**财星**且为命局用神 → 财运上升、收入增加
- 流年遇**官杀**且为命局用神 → 事业升迁、职权扩大
- 流年遇**食伤**且为命局用神 → 才华发挥、创业良机
- 流年遇**印星**且为命局用神 → 学习进步、贵人庇护
- 流年遇**比劫**且为命局用神 → 合作发展、人脉拓展
- 若以上十神为忌神则反断（如流年逢忌神财星 → 破财、花销大）

#### 3.3 分析范围
- 重点分析当前大运与最近 1-3 年的流年吉凶
- 关注大运与命局的"天克地冲"、"岁运并临"等特殊组合

### 第四阶段：生成最终报告

输出一份结构完整的《人生运势指南》，包含以下章节：

1. **命造总评**：一句话概括格局与层次（如"身强偏财格配七杀，适合竞争性行业，中年大发之命"）。
2. **性格深度剖析**：
   - 显性性格与隐性心理
   - 性格中的优势与需注意之处
3. **事业财富规划**：
   - 格局倾向于贵还是富
   - 适合行业、职场建议
   - 财运起伏与大运配合
4. **情感婚姻建议**：
   - 日支（夫妻宫）分析
   - 男命看财星、女命看官杀
   - 择偶方向与相处之道
5. **健康养生**：五行偏枯对应的身体部位及养生建议。
6. **近期运势预警**：未来 1-3 年的机遇与挑战，配合干支依据。
7. **改运建议**：基于用神喜忌的颜色、方位、饰品、行为调整建议。
