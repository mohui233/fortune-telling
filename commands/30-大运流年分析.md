# 大运流年分析

大运干支、顺逆、起运岁数一律以脚本 `## 大运` 段为准（引用卡片 YS-0001：论运与看命无二法）。本阶段在命局结论之上叠加大运、流年两层。

## 一、大运与命局互动

对当前大运及前后一步逐项判断：

| 判断项 | 规则 |
| :--- | :--- |
| 大运十神 | 脚本大运表已标注每步十神，直接引用 |
| 喜忌 | 大运干支五行为用神 → 发展期；为忌神 → 考验期；用神被命局合化 → 打折扣；忌神被命局克制 → 凶中有救 |
| 管年口径 | 干支共管十年、**前五年干气显、后五年支气显**（`rules/7-流派分歧与取舍.md` 第 3 条，折中口径非定论）——当前处于大运第几年，先看该段干/支 |
| 换运年 | 大运交接年份（如 2026→2027）变动较大，提示用户谨慎决策（`rules/7-流派分歧与取舍.md` 第 6 条） |
| 生扶克泄 | 大运对日主是生扶还是克泄耗，结合强弱结论 |
| 引动关系 | 大运地支与四支构成冲/合/刑（对照脚本关系表扩展到该支），冲日支 → 婚姻宫动；冲月支 → 环境平台变动 |
| 三合三会 | 大运地支与命局成三合局/三会局，该五行力量显著增强 |

起运前（脚本"以月柱论小运"）：按月柱干支论童年运势。

## 二、流年评估（命局 + 大运 + 流年三层）

流年要点直接读脚本 `## 流年要点` 段（含十神、与四支的冲合刑害、岁运并临、天克地冲标记），再按 `rules/2-十神详解.md` 十神倾向解读：

- 流年十神为用神 → 对应领域的机遇年；为忌神 → 挑战年（措辞遵循 `rules/4-解盘原则.md`）。
- 脚本已标的 ⚠ 岁运并临：力量加倍，吉凶随原局喜忌放大。
- 脚本已标的 ⚠ 天克地冲：重大变动年（换工作/搬家/关系变动倾向），只提示"变动可能性大"，不断言吉凶。
- 需要补充流年时重跑脚本加 `--liunian 年份`，不得口算干支。

## 三、历史事件校准（全流程模式必做，专题模式可选）

**跳过条件**：用户不在场、异步/批量执行或用户不回应时，跳过本节并在报告中省略校准段——严禁编造用户反馈、严禁把"假设的验证"写进依据索引。仅在用户实际回应后执行：

提出 **3 个**可验证的已发生事件窗口，请用户反馈，例：

> 依据您 XX-XX 年行 XX 大运（十神），那几年呈现"竞争压力大、岗位变动"的特征，实际是否如此？

- 用户确认 → 相应判断记为"已验证"，成稿时优先引用。
- 用户否认 → 检查该判断的证据链：若孤证或依据牵强，下调该倾向的表述强度；若依据扎实，保留判断但标注"命理显示如此，现实表现可能滞后"。
- 校准反馈只修正"倾向性表述强度"，不得倒推改排盘、改格局。

## 输出物

当前大运定性 + 未来 1-3 年流年要点 + 校准结论，每条带命盘与大运依据。进入 `40-成稿与依据索引.md`。
