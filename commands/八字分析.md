# 八字分析 (Bazi Analysis)

## 步骤一：获取命盘信息

1. **检查输入**：判断用户是否直接提供了"四柱干支"或"大运信息"。
   - 若用户已提供完整排盘信息（如："甲子年 丙寅月……"），则**直接使用用户数据**，跳过排盘步骤。
2. **检查工具（若需排盘）**：
   - 若用户仅提供了出生时间，检查环境中是否存在 `mingpan` MCP 工具（如 `bazi_basic`）。
3. **执行排盘**：
   - **Mode A (MCP)**：调用 `bazi_basic(year, month, day, hour)` 获取精准结果。
   - **Mode B (估算)**：若无 MCP 工具，根据用户提供的出生时间，**自行推算**干支。
     - *警告*：必须在输出开头显著提示："因未连接专业排盘工具，节气交接时刻可能存在误差，建议核对。"
   - **必需信息**：四柱（年柱、月柱、日柱、时柱）、藏干、空亡、纳音。

## 步骤二：格局判断（参考 `rules/十神详解.md` 的格局速查）

### 2.1 定日主
- 确定日干（Day Master）及其五行属性。

### 2.2 审月令定格局
- **以月支本气为主**判断格局类型：
  - 月支藏干透出天干者，取为格局（如月支寅藏甲丙戊，天干透甲则甲为格局）。
  - 若月支藏干不透，取月支本气为格。
- **格局类型判断**：
  - **正官格**：月支本气为正官，或正官透出
  - **七杀格**：月支本气为七杀，或七杀透出
  - **正财格**：月支本气为正财，或正财透出
  - **偏财格**：月支本气为偏财，或偏财透出
  - **食神格**：月支本气为食神，或食神透出
  - **伤官格**：月支本气为伤官，或伤官透出
  - **正印格**：月支本气为正印，或正印透出
  - **偏印格**：月支本气为偏印，或偏印透出
  - **建禄格**：月支为日主临官位（甲生寅月、乙生卯月等）
  - **从格/化格**：参见 `rules/十神详解.md` 特殊格局

### 2.3 定强弱
采用**得令、得地、得势**三维评分法：

1. **得令（月支生扶）**：
   - 月支为日主之比劫印星（生扶）→ 得令
   - 月支为日主之食伤财官（克泄耗）→ 失令
2. **得地（地支有根）**：
   - 日干在年、月、日、时地支中有同类（如甲见寅卯辰未）→ 有根
   - 根的数量和位置决定强弱程度（日支之根最强）
3. **得势（天干同类多）**：
   - 年、月、时天干中比劫印星多 → 得势
   - 食伤财官多 → 不得势
4. **综合评判**：
   - 三得其二或以上 → 身强
   - 只得其一 → 偏强或偏弱（需结合格局）
   - 三者皆无 → 身弱（关注是否成从格）

## 步骤三：地支关系分析（刑冲合害）

地支之间的关系对命局影响巨大，不可遗漏。

### 3.1 六合（和谐、合作）
- 子丑合、寅亥合、卯戌合、辰酉合、巳申合、午未合

### 3.2 三合局（力量强大、方向一致）
- 申子辰合水局、寅午戌合火局、亥卯未合木局、巳酉丑合金局

### 3.3 六冲（冲突、变动、不稳定）
- 子午冲、丑未冲、寅申冲、卯酉冲、辰戌冲、巳亥冲
- 冲在月支 → 青年时期大变动
- 冲在日支 → 婚姻宫动荡
- 冲在时支 → 子女或晚年不稳

### 3.4 相刑（摩擦、纠纷、隐忧）
- 寅巳申三刑（无恩之刑）、丑戌未三刑（恃势之刑）、子卯刑（无礼之刑）
- 辰辰自刑、午午自刑、酉酉自刑、亥亥自刑

### 3.5 相害（暗中破坏、误会）
- 子未害、丑午害、寅巳害、卯辰害、申亥害、酉戌害

## 步骤四：用神选取（参考 `rules/十神详解.md` 用神体系）

按以下优先级选取用神：

1. **调候优先**：
   - 生于亥子丑月 → 急需火（丙）暖局
   - 生于巳午未月 → 急需水（壬/癸）润局
   - 生于辰戌丑未月 → 按寒暖燥湿判断
2. **扶抑其次**：
   - 身强 → 取官杀（克）、食伤（泄）、财星（耗）
   - 身弱 → 取印星（生）、比劫（扶）
3. **通关补充**：
   - 命局中两种五行相战 → 取能调和二者的五行
4. **病药配合**：
   - 某一五行过旺为"病" → 取能克制或泄耗该五行的为"药"

## 步骤五：神煞分析（参考 `rules/神煞规则.md`）

1. **查神煞**：根据 `rules/神煞规则.md`，查找命盘中的吉神与凶神。
2. **重点关注**：
   - 天乙贵人（贵人运、人际关系）
   - 禄神（健康根基、福气）
   - 将星（领导才能）
   - 桃花（异性缘、人缘）
   - 驿马（变动趋势）
   - 空亡（薄弱环节）
3. 参考 `rules/十神详解.md` 中的"强弱平衡"。

## 步骤六：综合解读（参考 `rules/解盘原则.md` 分析层级）

按照层级顺序解读：
1. 格局定性 → 2. 强弱判定 → 3. 用神忌神 → 4. 十神分析 → 5. 神煞加减

### 解读维度
1. **性格特征**：结合十神心性与五行属性（如食神主温和、伤官主叛逆、七杀主强势、正印主仁慈）
2. **事业财运**：分析财星与官杀的力量与组合，格局倾向于贵还是富
3. **婚姻情感**：日支（夫妻宫）为关键，男命看财星、女命看官杀
4. **健康养生**：五行偏枯之处易对应身体问题
