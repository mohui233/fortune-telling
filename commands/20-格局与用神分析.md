# 格局与用神分析

排盘事实以确认屏版本为准。本阶段所有判断引用 `rules/2-十神详解.md`、`rules/3-神煞规则.md` 的表，典籍论断引用 `rules/典籍卡片.md` 的卡片 ID；每形成一条结论随手记：`结论 + 命盘依据（柱位/干支/十神/关系） + 卡片ID（如有）`。

## 一、定日主

从脚本输出的日柱取日干及其五行。日主是十神与用神体系的原点，不得跳过。

## 二、审月令定格局（引用卡片 YL-0001、YL-0002、GJ-0001）

按 `rules/2-十神详解.md` 取格细则与格局速查：

1. 月支藏干透出天干者取为格局（**比肩/劫财透出不取格**，退回月支本气；建禄格、羊刃格按临官/羊刃位论）。
2. 月支藏干不透，取月支本气为格。
3. **杂气月退路**：辰戌丑未月本气为比劫且非临官/羊刃位、藏干又不透时，注明"未成传统正格"不强行命名，按全局组合定性（富格/贵格速查表）+ 旺衰扶抑取用。
4. 依次核对：正官/七杀/正财/偏财/食神/伤官/正印/偏印/建禄/羊刃格。
5. **特殊格局**（从格/化格）从严认定：满盘一类五行、日主无根无印方可论从（引用 GJ-0003 及其反例边界——有一点强根或印星即不从）。
6. 破格检查：成格之物被合被冲、忌神无制，须明确写出破格点（力量规则见 `rules/6-地支关系.md`）。

## 三、定强弱（引用卡片 WS-0001、WS-0002）

采用**得令、得地、得势**三维评分（细则与藏干力量权重见 `rules/2-十神详解.md` 用神判断流程）：

- 三得其二及以上 → 身强；只得其一 → 偏强或偏弱（结合格局）；三者皆无 → 身弱，并复查是否成从格。
- 月令被冲合明显减损其力量（冲重于刑害，引用 SH-0002 与 `rules/6-地支关系.md` 力量级）。

## 四、选用神（引用卡片 TH-0001/TH-0002、GJ-0002）

按 `rules/2-十神详解.md` 用神体系优先级：

1. **调候优先**：冬生急火、夏生急水、湿燥土月按寒暖燥湿。
2. **扶抑其次**：身强取克泄耗，身弱取生扶。
3. **通关兼顾**：两五行相战取通关之神。
4. **病药补充**：过旺为病，制泄为药。
5. 从格顺势：喜顺旺势之五行，忌逆。

用神选取必须与第二、三步的格局强弱结论自洽；若矛盾，回到格局复查，不得为了"好听"强行取用。

## 五、十神分布分析

按 `rules/2-十神详解.md` 十神四柱位置表，逐柱解读年/月/日/时十神组合倾向（性格、事业、财运、婚恋的倾向性）。要点：

- 同一十神不同柱位含义不同，必须区分。
- 不可仅凭单一十神断吉凶。
- 天干透出 vs 地支藏干的力量与显隐要区分（透干主外在表现，藏支主内在禀性）。

## 六、神煞加减（引用卡片 SH-0001）

只查脚本 `## 神煞` 段命中的条目（口径与 `rules/3-神煞规则.md` 同表）；解读遵循神煞使用原则：格局为先、用神为本、组合为重。脚本未命中的神煞不得凭记忆补写。

## 七、地支关系复核

脚本 `## 刑冲合害` 段逐条消化，解读规则见 `rules/6-地支关系.md`：先按力量级定轻重（冲最重、三合全会爆发、刑害为扰动），再结合宫位（日支=夫妻宫、月支=提纲）与十神解读，最后落建设性建议。本步骤只做解释，不得新增脚本未列的关系。

## 输出物

本阶段产出分析要点清单（不直接面向用户成稿）：格局定性、强弱、用神忌神、四柱十神倾向、神煞加减、关系影响，每条带依据。全流程模式继续进入 `30-大运流年分析.md`。
