# 命理咨询 (Fortune-Telling)

> "了解先天禀赋，规划更好的人生。"

输入出生时间（年月日时及性别），输出经过「排盘 → 定格局 → 选喜用 → 查神煞 → 推大运 → 判流年」递进式分析的全方位人生运势指南。基于八字十神、格局法、用神体系和神煞规则，结合现代心理咨询式的解盘原则。

## 目录结构

- `SKILL.md`：技能入口、触发方式、全局约束
- `rules/`：命理学核心方法论
  - `十神详解.md`：十神定义、生克关系、四柱位置含义、经典格局速查、用神体系
  - `神煞规则.md`：吉神/凶神/中性神煞的查法与解读，含神煞使用原则
  - `解盘原则.md`：递进式分析层级、核心价值观、伦理禁忌与输出规范
- `commands/`：完整执行流程与输出模板
  - `auto-fortune.md`：全流程运势分析（排盘 + 定格局 + 推大运 + 判流年）
  - `八字分析.md`：基础排盘、格局判断、用神选取与初步分析
- `README.md`：人工阅读说明

## 使用方式

触发指令 `/auto-fortune` 或 `/八字分析`，提供出生时间即可开始命理咨询。

## 核心方法论

1. **格局为先**：以月令为主判断格局类型（正官格、七杀格、食神格等），格局决定命盘层次的天花板
2. **用神为枢**：综合调候、扶抑、通关、病药四大用神类型，确定喜忌五行
3. **神煞为辅**：神煞是格局用神框架下的加减分项，不可喧宾夺主
4. **大运为导**：大运是命局的"导演"，好命走坏运难发挥，平庸命走好运亦能成就
5. **伦理为纲**：知命造命而非宿命论、建设性建议而非恐吓、言必有据而非妄断

## 核心理念

- **知命造命**：算命的目的是了解先天禀赋与后天运势，趋吉避凶，而非宿命论
- **建设性**：所有解读包含改进建议，指出的问题必给出化解方法
- **言必有据**：每一条结论都指明命盘依据
- **伦理底线**：严禁预测生死，严禁恐吓用户，不替人决策

## 维护约定

- 入口信息只写在 `SKILL.md`
- 执行步骤只写在 `commands/`
- 命理规则只写在 `rules/`
- 不在多个文件重复维护同一条规则
