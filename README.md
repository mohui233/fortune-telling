# 八字命理 Skill (Fortune-Telling)

> "了解先天禀赋，规划更好的人生。"

输入出生时间（年月日时及性别），输出经过「排盘 → 定格局 → 选喜用 → 查神煞 → 推大运 → 判流年」递进式分析、每条结论可回溯命盘依据与典籍出处的运势指南。

## 使用方式

触发指令 `/auto-fortune`（全流程）或 `/八字分析`（仅排盘+基础分析），或直接提供出生时间；也可带具体问题（感情/事业/某年运势）进入专题追问模式。

## 验证与维护

```bash
python tests/test_pai_pan.py        # 黄金锚点 + 跨实现交叉验证（秒级，日常回归）
python tests/test_authority.py      # 权威数据全量复测（约 40 秒，发版/改口径必跑）
python tests/test_authority.py --quick   # 权威数据抽样快检（秒级）
python scripts/pai_pan.py --year 1990 --month 5 --day 15 --hour 12:00 --sex 男
```

### 复测方法论（详见 tests/复测协议.md）

- **行业标准**：排盘层有国家标准 **GB/T 33661-2017《农历的编算和颁行》**（紫金山天文台：节气=太阳视黄经 15° 整数倍时刻，北京时间东经 120°）；解读层无行业标准答案，只有流派规则，故解读层复测只验"规则自洽 + 稳定可重复 + 有据可溯"。
- **三层复测**：L1 排盘（三道独立证据链：黄金锚点 / 独立实现交叉 / 权威数据全量）；L2 解读（黄金盘基准定性稳定性回归）；L3 交付（24 项质量核验，伦理红线零容忍）。
- **权威基线**：1900-2052 节气 3,672 条最大偏差 46 秒；日柱 55,883 天零偏差；换柱边界 1,836 条零错误（JPL DE421 星历数据，与紫金山官方值差 ≤30 秒）。
- **历史名人**：只作演示与三柱抽查（`tests/名人案例.md`），不作排盘证明、更不作解读准确证明——时辰多为野史倒推，后见之明偏差使"名人验证"在科学上无效。
- **可重复性**：排盘是纯函数（同输入必同输出、无网络依赖、时区硬编码）；权威数据随仓库固化；口径变更四处一体（脚本锚点、rules/1、rules/3、黄金测试），任一测试失败即阻断。

- 排盘口径四处一体：`rules/1-排盘口径.md`、`scripts/pai_pan.py` 头部锚点、`rules/3-神煞规则.md`、黄金测试——改一处必须同步其余三处。
- 入口信息只写在 `SKILL.md`，执行步骤只写在 `commands/`，命理规则只写在 `rules/`，不在多个文件重复维护同一条规则。
- 新增典籍卡片须六字段齐备，反例边界必填（详见 `rules/典籍卡片.md` 头部契约）。

## 核心理念

- **知命造命**：算命的目的是了解先天禀赋与后天运势，趋吉避凶，而非宿命论
- **建设性**：所有解读包含改进建议，指出的问题必给出化解方法
- **言必有据**：每一条结论都指明命盘依据与典籍出处，无据如实标注
- **伦理底线**：严禁预测生死，严禁恐吓用户，不替人决策
