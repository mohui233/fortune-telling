# Fortune Telling Plugin (算命插件)

一个基于中华传统术数（八字、神煞）的 AI 插件，旨在通过结构化的 Prompt 和 MCP 工具调用，提供专业、温暖且具有建设性的人生运势分析。

## 核心理念

- **架构模式**: 受 **Anthropic** 官方插件架构启发，采用 `commands` (SOP) + `skills` (Domain Knowledge) 的双层结构。既然 AI 能够处理复杂的法律与代码逻辑，它同样可以通过一套精准的 SOP，将晦涩难懂的传统术数逻辑“揉碎”并标准化，转化为可解释、可验证的咨询服务。
- **知识来源**: 核心算法逻辑参考 `mingpan-main` 项目，提取其定义与规则作为插件的“知识库”。
- **人机协作**: 
  - **AI (LLM)**: 负责语义理解、性格推断、建议生成、情感抚慰。
  - **Code (MCP)**: 负责排盘计算（节气、干支、神煞），确保数据准确。

## 功能列表

### Commands (指令)
- `/0_综合排盘`: 全流程人生分析（八字 + 大运 + 流年）。
- `/1_八字分析`: 基础排盘与性格、格局分析。

### Skills (技能/知识库)
- `/skills/1_十神详解`: 定义十神的含义与生克关系。
- `/skills/2_神煞规则`: 提供天乙贵人、驿马等神煞的查法。
- `/skills/3_解盘原则`: 规定输出风格（客观、温暖）与伦理禁忌（不测生死）。

## 为什么需要这个插件？

虽然大模型（LLM）本身具备一定的知识，但直接询问“帮我算命”往往存在以下问题：
1. **计算不准**: LLM 难以精确计算复杂的农历节气与干支转换（容易出现“伪科学”的排盘错误）。
2. **逻辑幻觉**: 在十神生克、神煞查法上可能张冠李戴。
3. **风格不可控**: 可能输出宿命论、消极或过于迷信的内容。

**本插件的价值**:
1. **标准化流程**: 强制模型按照“排盘 -> 定格 -> 分析 -> 建议”的 SOP 执行。
2. **知识增强**: 通过 Context 注入准确的规则（Skills），减少幻觉。
3. **伦理约束**: 明确“建设性”、“不恐吓”的原则，确保输出内容积极向上。
4. **灵活兼容**: 
   - **最佳体验**: 配合 `mingpan` MCP Server，实现“精准计算 + 智慧解读”。
   - **无 MCP 模式**: 支持用户手动输入排盘结果（如从其他 App 复制），插件仅负责“解盘”与“建议”，依然能提供高质量的咨询服务。

## 部署与使用

### 场景一：本地 IDE (Trae / Claude Desktop)
适合开发者或希望获得**精准计算**体验的用户。

**配置方法**:
1. 确保已安装 Node.js。
2. 插件已内置 `.mcp.json`，支持 MCP 的编辑器（如 Claude Desktop）会自动识别。
3. 若需手动配置，请在编辑器的 MCP 设置中添加：
   ```json
   "mingpan": {
     "command": "npx",
     "args": ["-y", "mingpan"]
   }
   ```

**使用示例**:
直接在对话框输入指令即可自动触发排盘工具：
```
/auto-fortune 1995 8 15 14:30 男 阳历
```
> 系统会自动调用 `mingpan` 工具计算干支，然后输出完整报告。

---

### 场景二：Gemini 网页版 (Gems)
适合无法安装本地环境，或仅需**咨询解盘**的用户。

**配置方法**:
1. 参考 `Gem 配置指南.md`，在 Gemini 中创建一个新的 Gem。
2. **不要**上传 `.mcp.json`。
3. 仅上传 `commands/` 和 `skills/` 下的所有 Markdown 文件作为知识库。

**使用示例**:
由于云端无法调用本地 MCP，你需要提供排盘信息（或让 AI 估算）：
```
/auto-fortune 1995 8 15 14:30 男 阳历
(附上排盘结果：乾造 乙亥 甲申 戊子 丙辰...)
```
> 或者直接报出生时间，AI 会尝试推算（会提示可能存在节气误差）。
